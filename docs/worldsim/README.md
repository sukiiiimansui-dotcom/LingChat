# 世界模拟 · 路线与实现

**总路线**：真实 2.5d 地图 ＋ 真实 3d 建筑（换掉原来那套「五层下钻 ＋ AI 实时生成街区」）。
下面按路线顺序，说每一步是**怎么落地的**。

## ① 数据：真数据 · 离线的 · 按格切

楼房 / 路网 / 片区名 / 水绿 全部来自公开真实数据 —— 楼房用 Overture Maps buildings（ODbL 1.0），
路网、片区名、水域绿地用 OpenStreetMap / Overpass（ODbL 1.0）。按格切成**离线包**，
每个包一份 `index.json` 写明来源与署名（画面上带可见署名，原句不改写）；城市由用户自己选下载哪一份。

实现：`wsOfflineFeed.ts` —— **一个取数管道**跑四种包（同一套格数学，只差"格边长"一个参数）；
水 / 绿地单独一层 `wsGwLayer.ts`。

## ② 画面：真 2.5d 底图 + 真脚印挤出的 3d 楼房

引擎 MapLibre GL JS（vendored 在 `public/vendor/`），底图之上是**我们自己的主题**
（`public/wstheme.json` · `wsMapTheme.ts` · `wsMapStyle.ts`）。

楼房**不是画的，是挤出来的**：用 Overture 的**真脚印**做 `fill-extrusion`（`bld-ext` / `bld-line` ＋阴影 AO），
所以楼的形状、朝向、退台都是那条街真实的样子。水 / 绿地是矢量面层；地名楼名是 DOM 标签层，带避让与上限（`wsNameLayer.ts`）。

## ③ 远处：近处实时画 / 远处预渲染（LOD）

一屏塞满真几何体会卡，所以分档：**近处实时**渲染，**远处换成我们自己的预渲染瓦片**（z6~z12，
风格取自同一套主题，不是拿别人的图）。切换用交叉过渡，避免跳变。

## ④ 一条硬边界：数据与渲染两条通道分开

数据层只放**真实**数据（Overture / OSM 的真脚印）；渲染层在远处可以有"用路网补出来的楼"，
但它**只存在于瓦片像素里**，不进任何数据接口 —— 免得 AI 对着不存在的楼去推理（设施摆位、寻路、距离都会错）。
